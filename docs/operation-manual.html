2. 首次安裝與設定

Step 1：安裝 App

  1. 使用 Android Studio 開啟專案
  2. 連接手機（開啟 USB 偵錯）
  3. 執行 assembleDebug 或直接 Run
  4. App 安裝後開啟

Step 2：連接遙控器與無人機

  1. 遙控器開機 → 手機插入遙控器 → 自動開啟 DJI App
  2. 確認 DJI MSDK 已正確初始化（主畫面顯示連線狀態）
  3. 無人機開機 → 等待 GPS 定位完成

Step 3：進入設定頁面

從主畫面進入 Settings 頁面，依序完成以下設定。

3.7 訊號平滑濾波

用於減少 GPS 座標跳動與 VirtualStick 指令高頻震動，提升環繞軌跡的圓度與穩定性。兩組參數都使用 EMA（指數移動平均）低通濾波演算法。

GPS 座標濾波（GPS EMA Alpha）

對 GPS 回傳的經緯度做平滑處理，減少因衛星訊號微小偏移造成的座標跳動。此濾波後的座標僅用於飛行控制（環繞、飛往目標），HUD 顯示仍使用原始座標。

欄位範圍預設說明
GPS 濾波係數0.2–0.80.4越小 → 濾波越強（更平滑但延遲增加）；越大 → 越即時（但跳動較明顯）

🛡️ 強濾波

0.2 — GPS 訊號不穩定時使用，犧牲即時性換取穩定

⚡ 弱濾波

0.8 — GPS 訊號良好時使用，減少延遲、提升即時性
延遲分析：alpha=0.4 時，GPS 濾波引入約 83ms 延遲（2.5 個 GPS 更新週期）。搭配指令平滑後，複合延遲約 183ms，在 2~5 m/s 環繞速度下僅造成 0.36~0.92m 偏移，可忽略。

指令平滑（CMD Smooth Alpha）

對 VirtualStick 發送的 pitch/roll/yaw 指令做平滑處理，減少電機高頻震動。採用 cold-start 保護：首幀直接採用真實值，避免從零收斂的延遲。

欄位範圍預設說明
指令平滑係數0.3–0.80.5越小 → 指令越平滑（電機動作更柔和）；越大 → 指令越即時（響應更快）

🎬 影片級平滑

0.3 — 拍攝穩定優先，電機動作最柔和

🕹️ 靈敏操控

0.8 — 響應優先，適合有風環境快速修正
建議：預設值 0.5 在大多數場景下已經足夠。若發現環繞影片有輕微抖動，可嘗試降到 0.3~0.4。若在強風環境下感覺修正不夠即時，可提高到 0.6~0.7。

4. 任務模式總覽

4.1 任務 A — 定點原地錄影 + 拍照

用途：建物、地標定點環繞拍攝

  1. 自動起飛 → 飛往目標座標
  2. 360° 原地 yaw 旋轉錄影
  3. 每 60° 拍一張（共 6 張）+ 俯視照 1 張（共 7 張）
  4. 自動返航降落 → 自動下載照片

所需參數：target（座標 + 高度）

4.2 任務 B — 環繞錄影

用途：以指定半徑環繞目標錄影（鏡頭持續朝向中心）

  1. 自動起飛 → 飛往目標座標（保持安全高度）
  2. 飛至環繞起點（目標北方 orbitRadius 處）
  3. 在環繞起點下降至環繞高度（避免在圓心下降時撞擊障礙物）
  4. 順時針環繞 360° 錄影（鏡頭鎖定中心）
  5. 停止錄影 → 自動返航降落

所需參數：target + orbit.radius > 0

4.3 任務 C — 螺旋上升錄影

用途：固定半徑螺旋上升，鏡頭持續鎖定中心（如繞塔上升）

  1. 自動起飛 → 飛往目標座標（保持安全高度）
  2. 飛至環繞起點（目標北方 orbitRadius 處）→ 在起點下降至起始高度
  3. 螺旋上升 N 圈（Z_min → Z_max），鏡頭動態調整鎖定中心
  4. 停止錄影 → 爬升至 target.alt → 自動返航降落

所需參數：target + orbit.radius ≥ 5 + orbit.max_alt + orbit.turns（3-10）

4.4 任務 D — 擴展螺旋上升錄影

用途：半徑隨高度擴展的螺旋上升（如繞建築物上升同時拉遠）

  1. 自動起飛 → 飛往目標座標（保持安全高度）
  2. 飛至環繞起點（目標北方 rStart 處）→ 在起點下降至起始高度
  3. 螺旋上升 N 圈，半徑從 radius 線性擴展至 radius_end
  4. 停止錄影 → 爬升至 target.alt → 自動返航降落

所需參數：target + orbit.radius ≥ 5 + orbit.radius_end > radius + orbit.max_alt + orbit.turns（3-10）

4.5 多站任務（Multi-Stop）

用途：依序執行多個站點任務，站間不降落

  1. 自動起飛 → 飛往站點 1 → 執行任務
  2. 不降落 → 飛往站點 2 → 執行任務
  3. 重複直到所有站點完成
  4. 自動返航降落 → 統一下載所有照片

所需參數：stops 陣列（至少 2 站）

速度倍率（C/D 模式）

orbit_speed每圈時間適用場景
1.0（預設）60 秒優雅人像、房地產
1.540 秒動態內容、活動記錄
2.030 秒MV、舞蹈、運動

5.2 Topic 結構

所有 Topic 的 {prefix} 為 App 設定中的 Topic Prefix（預設 example/DRONE-001）。

Topic方向說明
{prefix}/command後端 → App飛行控制指令
{prefix}/mission/start後端 → App單站任務指令
{prefix}/mission/multi後端 → App多站任務指令
{prefix}/statusApp → 後端飛機狀態回報
{prefix}/ackApp → 後端指令執行確認
{prefix}/heartbeatApp → 後端連線心跳（每 5 秒）

5.3 指令 Topic：{prefix}/command

飛行控制的單一動作指令。

Payload 格式：

{
  "msg_id": "cmd_001",
  "cmd": "takeoff | rtl | cancel | reset",
  "timestamp": 1700000001000
}
cmd 值動作前置條件
takeoff自動起飛已連線、未起飛、狀態 IDLE
rtl自動返航已連線
cancel取消任務並返航任務執行中
reset重設狀態為 IDLE狀態 ERROR 或 IDLE

範例：

# 起飛
mosquitto_pub -h broker.emqx.io -t "example/DRONE-001/command" \
  -m '{"msg_id":"cmd_001","cmd":"takeoff","timestamp":1700000001000}'

# 返航
mosquitto_pub -h broker.emqx.io -t "example/DRONE-001/command" \
  -m '{"msg_id":"cmd_002","cmd":"rtl","timestamp":1700000002000}'

# 取消任務
mosquitto_pub -h broker.emqx.io -t "example/DRONE-001/command" \
  -m '{"msg_id":"cmd_003","cmd":"cancel","timestamp":1700000003000}'

# 重設狀態
mosquitto_pub -h broker.emqx.io -t "example/DRONE-001/command" \
  -m '{"msg_id":"cmd_004","cmd":"reset","timestamp":1700000004000}'

5.7 指令確認 Topic：{prefix}/ack

每條指令執行後的確認回應。

Payload 格式：

{
  "msg_id": "cmd_001",
  "action": "takeoff | rtl | cancel | reset | mission_start | multi_start",
  "status": "accepted | success | failed",
  "error_msg": "",
  "timestamp": 1700000001500
}

status 值：

  • accepted — 指令已接收，正在執行（僅 takeoff/rtl）
  • success — 執行成功
  • failed — 執行失敗（附 error_msg）

5.8 心跳 Topic：{prefix}/heartbeat

每 5 秒發布，用於確認 App 在線。

{
  "online": true,
  "timestamp": 1700000005000
}

5.9 訂閱 App Topic（後端接收）

後端需訂閱以下 Topic 來接收 App 的回報：

mosquitto_sub -h broker.emqx.io \
  -t "example/DRONE-001/status" \
  -t "example/DRONE-001/ack" \
  -t "example/DRONE-001/heartbeat"

6. 安全機制與注意事項

自動安全保護

機制說明
Flyaway 偵測環繞時每 50 次迴圈檢查距離，超出半徑 2.5 倍自動停止
電池監控環繞每 90° 檢查電量，低於門檻自動返航
Multi-Stop 電池預估每站完成後預估剩餘電量，不夠返航時提前中止
GPS 訊號檢查衛星數 < 8 或訊號 < LEVEL_3 時拒絕起飛
距離限制目標超出安全半徑（1000m）時拒絕執行
任務超時環繞 3 分鐘、螺旋 10 分鐘超時自動停止
ERROR 自動重置進入 ERROR 狀態 90 秒後自動重設為 IDLE

操作注意事項

  1. 同一時間只能執行一個任務，新指令會被拒絕
  2. msg_id 去重，同一 msg_id 只處理一次（快取 200 筆）
  3. 座標系統：所有 GPS 座標使用 WGS84，高度為相對起飛點高度
  4. 返航高度：App 會先爬升到 target.alt 再呼叫 RTH，但 DJI 飛控會自動爬升到 RTH_HEIGHT（30m）
  5. 照片下載：任務完成後自動等待 6 秒開始下載，下載期間啟動新任務可能衝突
  6. B/C/D 模式僅錄影不拍照，不觸發照片下載

7. 疑難排解

MQTT 連線失敗

  • 確認 Broker 位址與連接埠正確
  • 確認手機網路可連線（測試 Broker 需要外網）
  • 儲存設定後需重新連線（關閉 App 重開）

任務被拒絕執行

錯誤訊息原因解決方式
Mission already in progress有任務正在執行等任務完成或發送 cancel
GPS signal too weakGPS 衛星不足移到空曠處等待定位
Target exceeds safe radius目標超出 1000m縮短目標距離或調整限制
Mission B requires orbit blockB 模式未提供 orbit加入 orbit.radius > 0
Mission D: radius_end must be > radiusD 模式半徑設定錯誤確保 radius_end > radius

環繞拍攝圓心偏移

  • 檢查磁偏角設定是否正確（出國飛行時特別重要）
  • 確認 GPS 訊號良好（衛星數 ≥ 12）
  • 嘗試降低 GPS 濾波係數（如 0.2~0.3）加強座標平滑
  • 嘗試降低指令平滑係數（如 0.3~0.4）減少電機震動
  • 避免在磁干擾環境飛行（建築物、電塔附近）

狀態卡在 ERROR

發送 reset 指令恢復：

mosquitto_pub -h broker.emqx.io -t "example/DRONE-001/command" \
  -m '{"msg_id":"cmd_reset","cmd":"reset","timestamp":1700000009000}'
