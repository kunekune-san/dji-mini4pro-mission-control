📌 落地路徑（5 條，landingHandled AtomicBoolean 互斥）

  1. Motor-locked callback（正常）：照片下載 → setState(IDLE) → MQTT ack
  2. RTH timeout fallback（120s）：強制 IDLE + 補救下載
  3. cancelMission motor-locked：取消後落地 → setState(IDLE)
  4. cancelMission RTH timeout（60s）：強制 IDLE
  5. ERROR auto-reset（90s）：resetToIdle

🎯 任務案例 — 完整執行流程追蹤

以下四個案例追蹤任務 A/B/C/D 從收到 MQTT 指令到返航降落的完整程式碼路徑。標註每個步驟涉及的檔案、方法和關鍵程式碼行。

A

任務 A — 原地旋轉錄影 + 多角度拍照

最基礎的任務模式。飛到目標 → 原地 360° yaw 旋轉錄影 → 7 張多角度拍照 → 返航
radius = 0 最基礎

📥 Step 1：收到 MQTT 指令

後端發送 → {prefix}/mission/start { "msg_id": "msn_001", "mission": "A", "target": { "lat": 24.939, "lng": 121.347, "alt": 15.0 }, "orbit": { "gimbal_pitch": -45, "photo_gimbal_pitch": -30 }, "photo_count": 7 }
步驟檔案方法說明
1.1 MqttClientManager.kt messageArrived() Paho 回調收到訊息 → LRU 去重 → onMissionStartReceived 回調
1.2 MqttPayloadModels.kt MissionStartPayload.fromJson() 解析 JSON → 驗證 mission/target/orbit/photoCount → 回傳 Payload 或 null
1.3 MqttMissionBridge.kt handleMissionStart() MissionValidator 參數驗證 + 距離預檢 + GPS 就緒檢查 → 回 accepted ACK → 呼叫 startMission() → 任務完成後發送 success ACK

🛫 Step 2：起飛與飛行

步驟檔案方法狀態說明
2.1 MissionStateMachine.kt startMission() 驗證 IDLE 守衛 → GPS 檢查 → 距離預檢查 → 電量預估 → 立即 setState(TAKING_OFF)
2.2 FlightPhaseExecutor.kt performTakeoff() TAKING_OFF FlightManager.takeOff() → 等高度穩定 3 次讀數 → 15 秒超時
2.3 FlightPhaseExecutor.kt climbToAltitude(15.0) TAKING_OFF VirtualStick verticalThrottle = 5.0 m/s（CLIMB_THROTTLE）→ 到達目標高度 → 歸零
2.4 MissionStateMachine.kt startMission() 內 yaw 對齊 TAKING_OFF Yaw 旋轉讓機頭朝向目標 → YAW_ALIGN_PROPORTIONAL_GAIN = 0.8
2.5 MissionStateMachine.kt flyToTarget() FLYING_TO_TARGET 比例控制速度：speed = max(min(dist × gain, maxSpeed), 1.0) → 距離 < 2m 停止

🎬 Step 3：原地旋轉錄影（A 模式核心）

步驟檔案方法狀態說明
3.1 MissionStateMachine.kt executeStopCore() — 判斷 missionType == "A"（非 B 非 C）→ 呼叫 OrbitController.executeInPlaceRotation()
