1. 系統概述

🎯

系統定位

本系統是一套基於 DJI MSDK v5 的 Android 應用程式，用於控制 DJI Mini 4 Pro 無人機執行自動化拍攝任務。後端透過 MQTT 協定發送任務指令，App 自動完成起飛、飛行、環繞錄影、多角度拍照、返航降落等全流程。

2. 模組架構

2.1 DJI 硬體抽象層（dji/）

封裝所有 DJI MSDK v5 的 KeyManager 操作，提供簡潔的 Kotlin API 給上層使用。

✈️

2.2 任務控制層（mission/）

⚡

MissionStateMachine — 任務狀態機（核心）

整個系統的「大腦」，管理任務的完整生命週期。使用 Kotlin Coroutines 驅動，透過 StateFlow 對外暴露狀態。

object MissionStateMachine {
    enum class MissionState {
        IDLE, TAKING_OFF, FLYING_TO_TARGET,
        DESCENDING_TO_ORBIT_ALT, ORBITING, SPIRAL_ASCENDING,
        RECORDING_360, SHOOTING_PHOTOS, FLYING_TO_NEXT,
        RETURNING_HOME, ERROR
    }

    val state: StateFlow<MissionState>  // 對外暴露的狀態流

    suspend fun startMission(payload)   // 啟動單站任務
    suspend fun startMultiMission(payload) // 啟動多站任務
    fun cancelMission(reason: String?)   // 取消任務（安全返航，記錄原因）
    fun isDroneOnGround(): Boolean       // 三重安全檢查：!isFlying && !isMotorsOn && alt<1.0
    fun setupSafetyMonitoring(logger)    // 啟動 GPS/電池異常監控
}
🛫

FlightPhaseExecutor

internal object | 飛行階段執行器

  • performTakeoff() — 起飛（含重試 + 穩定等待）
  • climbToAltitude() — 爬升到指定高度
  • flyToTarget() — 飛往目標座標
  • descendToAltitude() — 下降到環繞高度
  • rotateYawForPhoto() — Yaw 旋轉拍照
  • estimateRemainingFlightBattery() — 電量預估
🔄

OrbitController

internal object | 環繞飛行控制

  • executeInPlaceRotation() — A 模式原地旋轉錄影
  • executeOrbitPhase() — B 模式環繞錄影
  • executeSpiralAscent() — C 模式螺旋上升錄影（固定半徑）
  • executeExpandingSpiral() — D 模式擴展螺旋上升錄影（半徑線性增長）

控制演算法：

  • 水平：切線速度 + PD 徑向修正 + D 模式徑向擴展
  • Yaw：PI 閉迴路 + bearingRate 前饋 + 視覺輔助修正
  • 垂直：基礎爬升率 + P 微調（高度-角度綁定）
  • 雲台：動態俯仰角 + 高度分段修正係數（5~50m）
  • 平滑：EMA 低通濾波（pitch/roll/yaw 獨立 alpha）

PhotoSequenceController

internal object
管理多角度拍照序列（每 60° 一張 + 天底一張）

VirtualStickController

internal object

VirtualStickParams

internal object

OrbitModeA / B / C / D

2.3 MQTT 通訊層（mqtt/）

📡

MQTT 通訊架構

後端 ──→ /command ──→ MqttClientManager ──→ MqttMissionBridge ──→ MissionStateMachine (訂閱/去重/重連) (指令驗證/轉換) (任務執行) 後端 ←── /status ──── MqttStatusReporter ←── FlightManager StateFlow 後端 ←── /ack ─────── MqttMissionBridge (每條指令的執行結果) 後端 ←── /heartbeat ── MqttStatusReporter (每 5 秒)

MqttClientManager

object | MQTT 連線管理

  • 自動重連（watchdog 每 10 秒檢查）
  • LRU 指令去重（500 條上限，淘汰最舊 200 條）
  • Thread-safe：AtomicBoolean + @Volatile

MqttMissionBridge

object | 指令 → 任務轉換

  • Payload 解析 → MissionValidator 集中驗證（進任務狀態機前攔截）
  • 任務狀態檢查（僅 IDLE 可啟動新任務）
  • 距離預檢（GeoMath，GPS 就緒時）
  • 兩階段 ACK（accepted → success/failed）
🛂

MissionValidator — 任務 payload 集中驗證

統一收攏所有 mission payload 的驗證規則，消除 handleMissionStart() 與 handleMultiStart() 之間的重複驗證邏輯。每個規則函式回傳 null = 通過，回傳 String = 錯誤訊息（可直接回給後端 ack）。

規則檢查內容適用模式
validateMissionTypemission 必須為 A/B/C/D全部
validateTargetlat ±90、lng ±180、alt 0~maxAlt全部
validatePhotoCountphoto_count 2~20全部
validateOrbitParamsalt 範圍、radius ≤ 1000m、gimbal_pitch -130~45、orbit_speed 1~5全部（有 orbit 時）
validateMissionB必須有 orbit 且 radius > 0B
validateMissionCradius ≥ 5m、max_alt > 0、turns 3~10C
validateMissionDC 全部規則 + radius_end > radius、final_heading 0~360°D
validateSingleMission / validateStop組合入口，一次跑完全部相關規則單站 / 多站
設計原則：驗證在進入 MissionStateMachine 之前完成，失敗即 publishErrorAck 拒絕執行，不碰無人機。純 Kotlin、零 Android/DJI 依賴，可搭配 MissionValidatorTest.kt 單元測試直接驗證規則正確性。

Topic 結構

Topic方向說明頻率

{prefix}/mission/start後端 → App單站任務指令—

🛡️

SafetyEventLogger

記錄所有安全相關事件到本地 CSV 檔案，用於事後分析。

異常類型觸發條件處置

5. 核心演算法

5.1 飛行速度控制

飛往目標時使用比例控制器，接近目標時自動減速：

// 飛行速度公式
val speed = max(
    min(distance * gain, maxSpeed),  // 比例控制 + 上限
    minSpeed                          // 最低速度保護
)

// 參數（可在 Settings UI 調整）
maxSpeed  = 1.0 ~ 13.0 m/s  // 最大飛行速度
gain      = 0.1 ~ 1.0       // 比例增益（越大減速越早）
minSpeed  = 1.0 m/s          // 最低速度（防風卡住）

速度遞減特性：距離越近速度越低，形成平滑減速曲線。

距離 20m → 速度 10.0 m/s（全速）
距離 10m → 速度  5.0 m/s
距離  5m → 速度  2.5 m/s
距離  2m → 速度  1.0 m/s（到達門檻，停止）

5.2 環繞控制（B/C/D 模式）

// 水平控制：切線速度 + PD 徑向修正
tangentialNorth = -sin(bearing) * orbitSpeed
tangentialEast  =  cos(bearing) * orbitSpeed

radialError = distFromCenter - orbitRadius
radialDerivative = (radialError - prevRadialError) / dt
radialSpeed = -(radialError * ORBIT_KP) - (radialDerivative * ORBIT_RADIAL_KD)

// 合成速度（等比例縮放確保速度大小 = orbitSpeed）
combined = tangential + radialCorrection [+ expansion]  // D 模式加 expansion
scale = orbitSpeed / combined.magnitude
param.pitch = combined.east * scale
param.roll  = combined.north * scale

// Yaw 控制：PI + 前饋 + 視覺修正
yawOutput = yawError*KP + yawIntegral*KI + feedforward + visualCorrection + manualOffset
關鍵設計：環繞速度由 MQTT 倍率 + 半徑決定，不受 Settings 飛行速度影響。速度 1× = 每圈 60 秒，速度 3× = 每圈 20 秒。水平速度上限 13 m/s（DJI Mini 4 Pro 硬體限制）。

5.3 螺旋上升（C/D 模式）

// 進度追蹤：角度與高度綁定
progress = totalAngle / totalAngleTarget   // 0.0 → 1.0
targetAlt = zMin + altitudeGain * progress

// 垂直控制：基礎爬升率 + P 微調
climbRate = altitudeGain / totalTimeSec
correction = (targetAlt - currentAlt) * SPIRAL_ALT_KP * 0.3   // 限幅 ±0.3
verticalThrottle = climbRate + correction   // 限幅 ±5.0 m/s

// 雲台動態調整（每 500ms，非阻塞）
h = currentAlt - 1.7   // 相對高度（扣除人眼高度）
altCorrection = getGimbalAltCorrection(currentAlt)   // 高度分段修正表
gimbalPitch = -atan(h * altCorrection / radius) * 180/PI

// D 模式額外：半徑隨進度線性增長
updatedRadius = rStart + radiusGain * progress
D 模式速度上限感知：當半徑增大導致切線速度觸碰 13 m/s 上限時，系統會自動調整總角度目標（對數修正），確保角度與高度同步完成。這可能導致實際飛行圈數多於 MQTT 設定值。

5.4 電量預估

// Multi-Stop 電量預估
totalDist = homeToFirst + sum(各站間距離) + lastToHome
totalDist += altitudeDiff * 2  // 爬升以 2 倍水平距離換算

batteryEstimate = totalDist / (maxRadius * 2) * 100
batteryEstimate = batteryEstimate.coerceIn(20, 60)

// 若電量不足，提前返航
if (currentBattery - batteryEstimate < 20) → RETURNING_HOME
