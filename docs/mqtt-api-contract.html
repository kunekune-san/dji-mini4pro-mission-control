3. 後端 → App 指令

3.1 飛行指令

SUB {prefix}/command

{
    "msg_id": "cmd_001",          // 必填，唯一 ID（去重用，200 條 LRU）
    "cmd": "takeoff",             // 必填，指令類型
    "timestamp": 1700000001000    // 必填，Unix timestamp (ms)
}
cmd說明前置條件ACK 行為
takeoff 自動起飛 state = IDLE 兩階段：accepted → success/failed
rtl 返航降落 飛行中（非 IDLE/RETURNING/ERROR） 活躍任務時改呼叫 cancelMission
cancel 取消任務 任務執行中 單階段：success
reset 重置為 IDLE state = ERROR 單階段：success

3.2 單站任務指令

SUB {prefix}/mission/start

{
    "msg_id": "msn_001",              // 必填，唯一 ID
    "mission": "A",                   // 必填，"A" | "B" | "C" | "D"
    "target": {                          // 必填
        "lat": 24.939543,               // 必填，-90 ~ 90
        "lng": 121.347937,              // 必填，-180 ~ 180
        "alt": 15.0                     // 必填，0 ~ maxFlightHeight
    },
    "orbit": {                           // 可選（A 模式可省略）
        "radius": 15.0,                  // 環繞半徑 (m)，0 = 原地
        "alt": 10.0,                     // 環繞高度 (m)，null = 用 target.alt
        "gimbal_pitch": -45.0,           // 錄影雲台角度，預設 -45
        "photo_gimbal_pitch": -30.0,     // 拍照雲台角度，預設 -45（僅 A 模式）
        "max_alt": 30.0,                  // 螺旋結束高度（C/D 模式必填）
        "turns": 4,                       // 旋轉圈數 3-10（C/D 模式必填）
        "radius_end": 20.0,               // 結束半徑（D 模式必填，需 > radius）
        "orbit_speed": 2.0               // 環繞速度倍率 1.0~5.0（選填，預設 1.0）
        "final_heading": 90.0,           // 結束後機頭轉向（C/D 選填，0~360，null=直接拉平）
    },
    "photo_count": 7,                    // 可選，拍照張數 2-20，預設 7
    "timestamp": 1700000002000            // 必填
}

驗證規則

單一來源：以下規則由 App 端 MissionValidator 集中執行。任一項失敗即回傳 failed ACK（error 為第一條失敗訊息），任務不會進入狀態機。
欄位驗證失敗時
msg_id不可為空回傳 failed ACK
mission"A" / "B" / "C" / "D"回傳 failed ACK
target.lat-90 ~ 90回傳 failed ACK
target.lng-180 ~ 180回傳 failed ACK
target.alt0 ~ maxFlightHeight回傳 failed ACK
photo_count2 ~ 20回傳 failed ACK
orbit.radius（通用）0 ~ 1000回傳 failed ACK
orbit.alt0 ~ maxFlightHeight（選填）回傳 failed ACK
orbit.gimbal_pitch-130 ~ 45回傳 failed ACK
orbit.photo_gimbal_pitch-130 ~ 45回傳 failed ACK
orbit.orbit_speed1.0 ~ 5.0回傳 failed ACK
orbit.radius (B)> 0（必填）回傳 failed ACK
orbit.radius (C/D)≥ 5回傳 failed ACK
orbit.max_alt (C/D)> 0 且 > orbit.alt（必填）回傳 failed ACK
orbit.turns (C/D)3 ~ 10（必填）回傳 failed ACK
orbit.radius_end (D)> radius 且 ≤ 1000（必填）回傳 failed ACK
orbit.final_heading (C/D)0 ~ 360（選填）回傳 failed ACK
距離≤ maxFlightRadius回傳 failed ACK

3.3 多站任務指令

SUB {prefix}/mission/multi

{
    "msg_id": "msn_multi_001",
    "stops": [                               // 必填，至少 2 站，最多 10 站
        {
            "mission": "A",
            "target": { "lat": 25.0, "lng": 121.5, "alt": 15.0 },
            "orbit": { "gimbal_pitch": -45 }
        },
        {
            "mission": "B",
            "target": { "lat": 25.001, "lng": 121.501, "alt": 20.0 },
            "orbit": { "radius": 15, "alt": 15, "gimbal_pitch": -45 }
        }
    ],
    "timestamp": 1700000002000
}

額外驗證

驗證項目說明
stops 數量2 ~ 10 站
任一站解析失敗整體回傳 failed
第一站距離Home → 第一站 ≤ maxFlightRadius
相鄰站距離每站之間 ≤ maxFlightRadius
每站的驗證同 mission/start

4. App → 後端回報

4.1 ACK 回報

PUB {prefix}/ack

兩階段 ACK（takeoff / rtl / mission/start / mission/multi）

// 第一階段：指令已收到並開始執行
{
    "msg_id": "msn_001",
    "status": "accepted",
    "action": "mission_start"
}

// 第二階段：執行成功
{
    "msg_id": "msn_001",
    "status": "success",
    "action": "mission_start"
}

// 第二階段：執行失敗
{
    "msg_id": "msn_001",
    "status": "failed",
    "action": "mission_start",
    "error": "GPS signal too weak"
}

單階段 ACK（cancel / reset）

{
    "msg_id": "cmd_003",
    "status": "success",
    "action": "cancel"
}

action 值一覽

action觸發來源
takeoff/command cmd=takeoff
rtl/command cmd=rtl
cancel/command cmd=cancel
reset/command cmd=reset
mission_start/mission/start
multi_start/mission/multi

4.2 狀態回報

PUB {prefix}/status

{
    "state": "FLYING_TO_TARGET",    // MissionState enum 名稱
    "lat": 24.939543,                 // 當前緯度
    "lng": 121.347937,                // 當前經度
    "alt": 28.5,                      // 相對高度 (m)
    "battery": 84,                    // 電池電量 (%)
    "heading": 180.5,                  // 機頭朝向 (°)
    "gps_satellites": 15,             // GPS 衛星數
    "timestamp": 1700000003000          // Unix timestamp (ms)
}

回報頻率

App 狀態頻率
飛行中（非 IDLE）每 10 秒
待機（IDLE）每 30 秒

關鍵狀態轉換即時回報

以下狀態轉換時會額外立即發送一次完整 status：

狀態觸發時機
TAKING_OFF開始起飛
RETURNING_HOME開始返航
IDLE任務完成 / 重置
ERROR發生錯誤
ORBITING開始環繞
SPIRAL_ASCENDING開始螺旋上升
GIMBAL_PULL_UPC/D 結束雲台拉平
FLYING_TO_NEXTMulti-Stop 站間飛行

所有 MissionState 值

state說明後端應如何解讀
IDLE待機可發送新任務
TAKING_OFF起飛中任務執行中，勿重複指令
FLYING_TO_TARGET飛往目標任務執行中
DESCENDING_TO_ORBIT_ALT下降到環繞高度任務執行中
ORBITING環繞錄影中任務執行中
SPIRAL_ASCENDING螺旋上升錄影中任務執行中
GIMBAL_PULL_UP雲台拉平過渡（C/D 結束，錄影中）任務收尾，接近 RETURNING_HOME
RECORDING_360原地旋轉錄影中任務執行中
SHOOTING_PHOTOS拍照中任務執行中
FLYING_TO_NEXT飛往下一站Multi-Stop 執行中
RETURNING_HOME返航中任務結束，等待 IDLE
ERROR錯誤可發送 reset 指令

4.3 心跳

PUB {prefix}/heartbeat

{
    "timestamp": 1700000003000
}

固定每 5 秒發送。後端可用於偵測 App 是否在線。

5. 錯誤碼與失敗原因

ACK error 欄位可能的值

error 訊息觸發條件建議處理
"GPS not ready"衛星 < 8 或訊號 < Level 3等待 GPS 穩定後重試
"Target exceeds safe radius"目標距離 > maxFlightRadius調整目標位置或限制值
"Battery risk: ..."電量 < 預估用量 + 10%（僅警告，不阻擋）可繼續執行，但有風險
"Battery below RTH threshold"電量 ≤ 返航門檻等待充電
"Unknown mission: ..."mission 不是 A/B/C/D修正 mission 欄位
"Invalid latitude: ..."lat 超出 -90~90檢查座標值
"Invalid longitude: ..."lng 超出 -180~180檢查座標值
"Invalid altitude: ... (max: ...)"alt 超出 0~maxFlightHeight調整高度
"Invalid photo_count: ... (must be 2~20)"photo_count 超出 2~20調整張數
"Invalid orbit.alt: ..."orbit.alt 超出 0~maxFlightHeight調整環繞高度
"Invalid orbit.radius: ..."orbit.radius 超出 0~1000調整半徑
"Invalid gimbal_pitch: ... (range: -130 to 45)"gimbal_pitch 超出 -130~45調整雲台角度
"Invalid photo_gimbal_pitch: ... (range: -130 to 45)"photo_gimbal_pitch 超出 -130~45調整雲台角度
"Invalid orbit_speed: ... (must be 1.0-5.0)"orbit_speed 超出 1.0~5.0調整速度倍率
"Mission B requires orbit block with radius > 0"B 模式缺少 orbit 或 radius ≤ 0提供 radius
"Mission C requires ..."C 模式參數不完整（radius ≥ 5、max_alt > 0、max_alt > alt、turns 3~10）補齊必要參數
"Mission D requires ..."D 模式參數不完整（含 radius_end > radius 且 ≤ 1000）補齊必要參數
"Mission D: final_heading (...) must be 0~360°"final_heading 超出 0~360調整角度
"Not in IDLE state"非 IDLE 時發送任務等待 IDLE 或發送 reset
"Parse error"JSON 格式錯誤檢查 JSON 結構
"Distance too far between stops"Multi-Stop 相鄰站距離過遠調整站點位置

6. 指令去重機制

⚠️ 重要：App 使用 msg_id 進行指令去重。相同 msg_id 的指令只會被處理一次。後端必須確保每條指令的 msg_id 唯一。
項目說明
去重容器LinkedHashSet（LRU 策略）
容量上限500 條
淘汰策略超過 500 時移除最舊 200 條
空 msg_id視為無效，回傳 failed ACK
